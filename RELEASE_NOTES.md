# PortSentinel 0.2.0 — Network Control Center

Первый исполняемый релиз PortSentinel.

## Главное

- самостоятельный portable `portsentinel.exe`;
- полноэкранная русская TUI-панель в стиле системной/hacker utility;
- управление стрелками и клавиатурой;
- живой TCP/UDP-монитор;
- PID и process mapping через Windows IP Helper API;
- IPv4/IPv6;
- listeners, connections, process cards и Quick Scan;
- анимации запуска и действий;
- встроенная проверка и установка следующих GitHub Releases.

## Скачать

Используйте `PortSentinel-0.2.0-win-x64.zip`. Файл `.sha256` содержит контрольную сумму архива.

Полностью распакуйте архив перед запуском.

# 🎛️ Интерфейс PortSentinel

PortSentinel запускается как самостоятельная полноэкранная консольная программа. CMD или Windows Terminal используются только как окно, внутри которого программа полностью рисует собственную панель.

## Главный экран

Панель состоит из:

- ASCII-логотипа;
- строки версии и режима;
- вертикального меню;
- цветовых статусов;
- подсказок управления.

Выбранный пункт подсвечивается и отмечается символом `▶`.

## Экраны

- **Live Network Monitor** — обновление TCP/UDP приблизительно раз в секунду;
- **Listening Ports** — TCP listeners и UDP endpoints;
- **Active Connections** — текущие TCP-соединения;
- **Process Inspector** — выбор процесса стрелками и подробная карточка;
- **Quick Scan** — explainable findings без malware verdict;
- **Update Center** — GitHub Releases, ZIP и SHA-256.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Перемещение по меню и процессам |
| `W` / `S` | Альтернативная навигация в главном меню |
| `Enter` | Открыть выбранный экран или карточку |
| `0`–`7` | Быстрый переход |
| `R` | Немедленный сетевой снимок |
| `Esc` / `Q` | Возврат или выход |

## Анимации

В v0.2.0 используются:

- загрузочная заставка;
- progress bar инициализации;
- spinner сетевого снимка и проверки Release;
- цветовые markers новых записей, listeners и findings.

Анимации отключаются параметром:

```powershell
portsentinel.exe --no-animation
```

Они автоматически отключены при перенаправленном выводе.

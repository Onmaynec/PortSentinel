# 🔐 Security Policy

## Поддерживаемые версии

PortSentinel пока не имеет опубликованных релизов. После появления release-веток таблица поддерживаемых версий будет добавлена сюда.

## Сообщение об уязвимости

Не публикуйте потенциальную уязвимость сразу в открытом Issue, если она может подвергнуть пользователей риску. Используйте GitHub Private Vulnerability Reporting, когда эта функция будет включена для репозитория.

В сообщении укажите:

- затронутую версию или commit;
- Windows version и architecture;
- минимальные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- возможное влияние;
- безопасный proof of concept без секретов и чужих данных.

## Границы безопасности проекта

PortSentinel не должен:

- автоматически блокировать процессы;
- изменять или удалять сторонние Firewall rules;
- собирать payload, токены, cookies, пароли или TLS content;
- выполнять импортированные файлы;
- запускать команды через shell interpolation;
- логировать secrets или отключённые privacy-поля.

Системные изменения допускаются только через отдельные команды с plan, dry-run, подтверждением, audit log и rollback.
